# 후쿠오카 가족여행 가이드 (2026.11.19–21)

모바일용 여행 안내 페이지. `index.html` 한 파일로 동작합니다.

## 배포 (GitHub Pages)

1. GitHub에서 새 저장소 만들기 (예: `fukuoka-trip`, Public)
2. `index.html`, `README.md` 업로드 → Commit
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/fukuoka-trip/` 접속

## 탭 바로가기 링크

- 항공·숙소: `…/#stay`
- 일정 (날짜별 상세 + 근처 볼거리): `…/#plan`
- 맛집: `…/#food`
- 쇼핑: `…/#shop`
- 정보 (날씨·환율·면세·이동·비상연락): `…/#info`
